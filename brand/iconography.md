# Iconography & illustration

## Icon style

| Rule | Spec |
|------|------|
| Stroke | 1.5px (`--inferix-icon-stroke`) |
| Cap / join | round |
| Corners | slightly rounded; match `--inferix-radius-sm` feel |
| Sizes | 16 / 20 / 24 (`--inferix-icon-size-*`) |
| Color | ink by default; accent for selected / active |
| Grid | optically centered in square viewBox `0 0 24 24` |

No filled-only icon sets for product nav — outline-first. Soft fills OK for product tiles on accent-soft.

## Illustration & photography direction

1. **Diagrams > stock photos.** Prefer product architecture diagrams, flow (gateway → route → trace → drift → retrain), and UI chrome.
2. **Product UI as hero visual.** Full-bleed TraceForge-like panels beat abstract 3D blobs.
3. **No generic AI stock** (glowing brains, robot hands, purple nebulae).
4. **Photography** (if any): real desks / terminals, desaturated, cool-neutral — secondary to product UI.
5. **Empty states:** simple line illustrations matching icon stroke weight.
