# Logo system

## Concept

The mark is a **rounded square with ascending telemetry bars** — a control-plane signal: inference activity, routing load, and health over time. The fourth bar is quieter (opacity) to suggest monitoring / watchfulness (DriftWatch), not just raw throughput.

Fits Inferix because the brand is about **seeing and steering** agent/inference traffic — not a chat bubble, not a generic neural node.

## Clearspace

Minimum clearspace = **0.5 × mark height** on all sides. Do not crowd with other logos or dense UI chrome.

## Minimum sizes

| Context | Min mark |
|---------|----------|
| Digital UI | 16px |
| Favicon | 16px (simplified bars OK) |
| Print / lockup | mark ≥ 24px; full horizontal lockup ≥ 120px wide |

## Do’s

- Use mark + Fraunces wordmark lockup on light bg
- Use inverse lockup on ink / accent dark strips
- Keep electric violet `#5B3FD1` on light; white mark plate on dark
- Maintain bar proportions and corner radius

## Don’ts

- Stretch or squish
- Recolor off-palette (no teal, gold, arbitrary gradients)
- Add drop shadows, glows, or outlines around the mark
- Rotate or rearrange bars
- Place mark on busy photography without a solid plate
- Use Inter (or other sans) for the wordmark
